# PMW3610 ドライバ (roBa 用に取り込み)

[kumamuk-git/zmk-pmw3610-driver](https://github.com/kumamuk-git/zmk-pmw3610-driver) の `main` (5e04553) をこのリポジトリに取り込み、次の変更を加えたもの。

## 変更点: 起動不良からの自動復帰

この個体のセンサーは、電源を入れた直後に正しく立ち上がらないことがある (自己診断の失敗、または初期化は成功するのにボール表面が見えない状態)。通電から数分経つまでは初期化し直しても戻らず、元のドライバは再試行しないため、次に再起動するまでトラックボールが動かなかった。

`src/pmw3610.c` の `recovery_work_cb` が、正常な読み取りを確認できるまで数秒おきに初期化をやり直す。正常を確認したあとは 60 秒おきの見回りだけを行う。

ハード側 (センサー基板) を直したら、この取り込みをやめて `config/west.yml` で元のドライバを参照する形に戻してよい。
